COMPENSADOR CNC - INSTRUCCIONES (Ubuntu / Windows XP sin internet)
===================================================================

CONTENIDO DE ESTA CARPETA:
- compensador.py        -> nucleo 
- compensador_gui.py    -> interfaz gráfica (doble-click)
- example.txt           -> G-code de ejemplo genérico
- LEEME.txt             -> este archivo

-------------------------------------------------------------------
A) EN UBUNTU / LINUX
-------------------------------------------------------------------
1. Instalar Tkinter si falta:
   sudo apt update && sudo apt install python3-tk -y

2. Ejecutar:
   python3 compensador_gui.py

3. Uso:
   - [Examinar...] selecciona tu archivo G-code (.txt solo)
   - Pulsa "Agregar punto" y rellena X  Y  Z por fila:
        X [0.000]     Y [0.000]    Z [0.000]
        X [100.000]   Y [0.000]    Z [0.120]
     Minimo 3 puntos, 4-7 recomendados. Usa punto o coma.
   - Pulsa COMPENSAR
   - Se crea archivo_COMPENSADO.txt en la misma carpeta.

-------------------------------------------------------------------
B) EN WINDOWS XP (sin internet)
-------------------------------------------------------------------
1. En PC con internet descarga python-3.4.4.msi (20MB) de python.org al pendrive.
2. En XP doble-click -> Siguiente -> marcar Tcl/Tk -> C:\Python34
3. Copia compensador.py + compensador_gui.py JUNTOS a la misma carpeta.
4. Doble-click compensador_gui.py -> Abrir con C:\Python34\pythonw.exe.

Uso idéntico a Ubuntu.

-------------------------------------------------------------------
C) CONSEJOS GENERALES
-------------------------------------------------------------------
- Pon coordenadas 0 de la maquina reales y palpa siempre con la misma herramienta que fresara.
- Intenta cubrir toda la superficie a mecanizar (esquinas y centro).
- Si el log indica "Error máximo >0.2mm" revisa las mediciones.
- Haz siempre una prueba en aire antes de fresar. Sube el eje Z 5 mm exactos (por ejemplo), confirma que ese es el nuevo punto 0 de Z y prueba. Después baja -5 mm, ajusta a 0 y mecaniza de verdad.
